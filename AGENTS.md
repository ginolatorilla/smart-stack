# AGENTS Guidance

Repo contains skills for AI agent harnesses.

## Skills

### Software architecture

- `arch-docs`: maintain ADRs, invariants, components.
- `merge-arch-proposals`: combine proposals then run `arch-docs`.
- `project-planning`: project plan from architecture docs.
- `api-contract-designer`: design API interfaces from architecture docs.

### Miscellaneous

- `my-writing-style`: agents mimic how you write.
